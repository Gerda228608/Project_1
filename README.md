## 📌 Тема проекта

> **Система мониторинга промышленных объектов по данным дистанционного зондирования Земли: раннее выявление деформаций дамб хвостохранилищ и бортов карьеров, просадок мерзлоты под объектами инфраструктуры, угроз растительности для ЛЭП и прогноз пожарного риска.**

Проект объединяет четыре прикладные задачи на общей платформе обработки спутниковых данных. Две из них решаются радарной интерферометрией (InSAR), две оптическими снимками и табличным ML поверх геоданных.

| # | Задача | Что следим | Технология | Данные |
|---|--------|-----------|------------|--------|
| 1 | 🏗️ **Дамбы и карьеры** | Не начинает ли «ползти» дамба хвостохранилища или борт карьера | InSAR, временные ряды PS/SBAS, прогноз момента разрушения | Sentinel‑1, NISAR, Кондор‑ФКА |
| 2 | 🧊 **Вечная мерзлота** | Просадка грунта под трубопроводами, резервуарами и опорами на севере | InSAR, сезонная декомпозиция рядов деформаций | Sentinel‑1, NISAR, ALOS‑2 |
| 3 | 🌲 **Деревья у ЛЭП** | Деревья, которые дорастут до проводов или упадут на линию | Карты высоты полога, детекция крон, прогноз роста | Sentinel‑2, ICESat‑2, Ресурс‑П / Аист‑2Т |
| 4 | 🔥 **Пожарный риск** | Где лес рядом с линиями и подстанциями может загореться | GBDT по пожарной погоде и топливу, U‑Net для распространения | FIRMS, MCD64A1, ERA5, Sentinel‑2 |

## 🔬 Ключевые выводы исследования (этап 0)

- **Готовых размеченных датасетов под наши объекты нет** — ни по хвостохранилищам, ни по российской мерзлоте, ни по спутниковым коридорам ЛЭП, ни по возгораниям от ЛЭП в РФ. Есть близкие аналоги для предобучения; разметку строим сами.
- **Sentinel‑1** после вывода S1A (июнь 2026) работает в составе S1C + S1D с 6‑дневным циклом; в Арктике эффективно 2–3 дня. **NISAR** (L‑band, бесплатно, с июня 2026) — ключевой новый источник для тундры и залесённых склонов.
- **Санкционные ограничения:** западные снимки 30–50 см и X‑band SAR недоступны. Отечественный потолок — Ресурс‑П 0.7 м, Аист‑2Т 1.6 м стерео, Канопус‑В 2–3 м; доступ к InSAR‑пригодным данным Кондор‑ФКА нужно выяснять.
- **GEDI** не покрывает Россию севернее 51.6° — для высоты леса используем ICESat‑2 ATL08 и бореальную карту ORNL 30 м.
- **Foundation‑модели**, предобученной на интерферометрической фазе, не существует — открытая научная ниша.
- Для вероятности возгорания **GBDT не уступает нейросетям** (Красноярск 2025 F1 0.89, Иркутск AUC 0.96); для распространения U‑Net/ConvLSTM упираются в F1 ≈ 0.6.

Подробный обзор с таблицами датасетов, ссылками и расчётами — в [`docs/data_review.md`](docs/data_review.md).

## 💾 Требования к ресурсам

| Ресурс | Оценка | Комментарий |
|--------|--------|-------------|
| 💽 Диск | **2–4 ТБ** (экономно ~1.5 ТБ) | Один трек Sentinel‑1 100×100 км за 3 года: 0.7–1.4 ТБ SLC или 0.2–0.4 ТБ burst‑продуктов; оптику читать через STAC окнами |
| 🧠 RAM / CPU | **64 ГБ, 16 ядер** | Узкое место — InSAR‑обработка (topsStack, MintPy на полном фрейме) |
| 🎮 GPU | **1 × 24 ГБ** (RTX 3090/4090, A10) | U‑Net/Swin 256–512 px, патч‑классификаторы InSAR; GBDT без GPU. Полное дообучение FM — 40–80 ГБ, заменяется LoRA |
